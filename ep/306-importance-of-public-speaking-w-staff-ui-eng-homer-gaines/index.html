ep 306 · dec 13, 2023

importance of public speaking w/ staff ui eng, homer gaines

guest: homer gaines, staff ui engineer, specializing in ui, ux and accessibility

  • treat accessibility as part of ux, not a separate add-on, since every user still interacts with the same product
  • learn accessibility fundamentals first, since tools and trends change but core principles stay the same
  • pick a topic you can talk about for 10 to 15 minutes with zero prep as your entry point into public speaking
  • expect burnout from the conference circuit and plan for the toll it takes on family and energy
  • public speaking builds real relationships and opens doors, so start small with lightning talks and build up
