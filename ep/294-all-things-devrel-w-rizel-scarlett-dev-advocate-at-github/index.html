all things devrel w/rizel scarlett, dev advocate at github

guest: rizel scarlett, developer advocate at github

  • devrel sits between the company and developers, showing how to use a product while bringing community feedback back to the product team
  • developers trust real demos and live coding more than marketing claims, so show the product in action instead of just promoting it
  • if you want to break into devrel, look for junior developer advocate roles and communities like devrel-focused discords or newsletters that post openings
  • building in public, even posting basic learning notes like how you made a button in html, helps hiring managers see you understand the process
  • think of brand as your online reputation, built by consistently sharing what you are learning rather than waiting until you feel like an expert
