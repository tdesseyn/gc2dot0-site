level up your career w/ david pine, content developer at microsoft

guest: david pine, content developer at microsoft

  • start open source contributions small by browsing github.com and watching repositories before jumping into code
  • check a repository's contributing markdown file first to learn exactly what maintainers expect from new contributors
  • treat github activity as a networking tool since recruiters can use it to spot engaged developers
  • at conferences spend real time in the hallway track asking questions and talking to people between sessions
  • big tech roles often come from letting your passion show through speaking, blogging, and community involvement rather than chasing buzzwords
