ep 354 · apr 15, 2024

how to contribute to open source the right way w/ bekah weigel

guest: bekah weigel, developer experience lead at opensauce

  • start contributing to open source by checking the project's github and looking for a contributing.md file before asking questions
  • read the docs and readme first, since answering questions you could have solved yourself burns out maintainers
  • ask questions in the open issue or pr instead of dming maintainers directly, since transparency is the norm in open source
  • pick open source issues that target skills missing from your resume, like documentation or a specific framework, to grow and get noticed
  • leadership, clear communication, and mentoring others make people stand out and get recommended faster when job searching
