questions this episode answers

what does subhash jaini say about using synonyms like spring boot instead of java on a resume?

on guidance counselor 2.0, subhash jaini explains that applicant tracking systems do not recognize synonyms, so using spring boot will not count as java experience. he emphasizes that you must match the exact keywords and phrasing from the job description because ats algorithms look for specific registered skills like python framework rather than just python. if the system is looking for a keyword and you use a related term instead, you will not get credit for that skill.

where does subhash jaini say to put unpaid projects on a resume for ats systems?

on guidance counselor 2.0, subhash jaini recommends creating a separate projects section rather than putting unpaid work under work experience. he explains that projects are scraped by ats systems in a way that handles overlapping dates better, while putting projects in work experience can cause the system to do funky things with timeframes. if you put something in work experience, the ats sometimes only pulls the latest job and struggles with overlapping employment periods.

how does subhash jaini recommend testing how an ats will parse your resume?

on guidance counselor 2.0, subhash jaini suggests applying to a random job on the same ats system you plan to use, just to see how it parses your information. he explains that you can apply to a workday job you do not actually want and check how it extracts your name, address and other details, then reformat your resume if needed. you should test this on different systems like workday, greenhouse and lever to optimize your resume for each one before applying to jobs you actually want.
