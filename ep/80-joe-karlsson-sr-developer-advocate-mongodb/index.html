ep 80 · sep 20, 2021

joe karlsson, sr. developer advocate @ mongodb

guest: joe karlsson, sr. developer advocate at mongodb

  • senior devs often code less because they create bigger value coaching teams and unblocking work than writing every pr themselves
  • leaders should ask senior engineers what they actually want instead of assuming everyone wants to stop coding or start managing
  • promoting someone just because they write great code can create a manager who is weak with people, aim to grow both skill sets
  • when building teams, favor mostly internal promotions with some fresh outside hires to balance stability and new ideas
  • junior engineers get overlooked because companies fear training costs, but a strong onboarding structure lets juniors scale senior output too
