ep 80 · sep 20, 2021

joe karlsson, sr. developer advocate @ mongodb

guest: joe karlsson, sr. developer advocate at mongodb

  • senior devs often code less because they create bigger value coaching teams and unblocking work than writing every pr themselves
  • leaders should ask senior engineers what they actually want instead of assuming everyone wants to stop coding or start managing
  • promoting someone just because they write great code can create a manager who is weak with people, aim to grow both skill sets
  • when building teams, favor mostly internal promotions with some fresh outside hires to balance stability and new ideas
  • junior engineers get overlooked because companies fear training costs, but a strong onboarding structure lets juniors scale senior output too

questions this episode answers

what does joe karlsson say about why senior developers code less?

on guidance counselor 2.0, joe karlsson says senior developers code less because they maximize value by coaching teams and removing blockers rather than writing every pull request themselves. if a senior dev becomes the bottleneck for code reviews and merges, they slow down the entire team. karlsson explains that empowering junior developers to explore codebases and write code creates a multiplier effect that produces more output than if the senior wrote all the code alone.

why is tech leadership so bad according to joe karlsson?

on guidance counselor 2.0, joe karlsson says tech leadership is weak because companies promote engineers who are great at coding into management roles, but coding and managing people are completely different skill sets. he argues that organizations should promote people who want to manage and study people skills, not just people who know code well. karlsson says he would rather promote someone good at managing humans than someone good at writing code if he had to choose.
