building your ai job search system

guest: subhash, data scientist

  • use the company's own career site instead of job boards like glassdoor when applying
  • match the exact wording from the job description including phrases like python framework not just python
  • put unpaid projects under a dedicated projects section rather than work experience so it scrapes correctly
  • test how an ats parses your resume by applying to a random job on that same system before applying for real
  • give ai a clean yaml file of your experience instead of your formatted resume when generating tailored versions
