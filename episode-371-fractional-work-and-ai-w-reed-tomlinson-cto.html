about this episode

on this episode of guidance counselor 2.0, taylor desseyn talks with reed tomlinson: fractional cto work, contracting vs full-time jobs, ai tools, and how to specialize in tech without competing directly with ai.

fractional work fills gaps when companies need expertise but can't hire full-time, often to fix crises or validate direction. get yourself on people's radar through linkedin, networking events, and talks rather than just grinding technical certifications. differentiate by combining technical skills with subject matter expertise or soft skills instead of trying to be the best coder. ai tools write code but you need strong code review skills to catch errors and ensure it actually solves the problem. junior developers should focus on understanding why code works and knowing product behavior to add value beyond what ai can do. when using ai coding tools, treat code review and understanding why code works as the real skill, not just accepting autocomplete.
